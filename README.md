# Bayt real estate platform

The first website and web dashboards are in [`web/`](web/README.md).

Start locally with `cd web && npm ci && npm run dev`.

The Supabase schema and first-admin setup are in `web/supabase/`. They must be run by the project owner before live listing workflows are available. The website includes a clearly labeled isolated demonstration mode for review.

Approved direction: Atelier, warm limestone and espresso, Syrian house logo, Arabic-first RTL with English available. Native iPhone and Android apps remain a subsequent phase; the mobile folder is currently empty.
